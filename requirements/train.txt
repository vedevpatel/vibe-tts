# Why a separate environment: datasets 3.6.0 requires fsspec<=2025.3.0 but base.txt pins
# fsspec==2026.9.0, so the training packages cannot join the inference environment without moving
# a pin the working inference setup was verified with. datasets is held below 4.0 because 4.x

# upstream training script indexes. transformers stays 4.46.1 (base.txt).
#
# Provenance: resolved with `uv pip compile` against base.txt (fsspec removed) and
# requirements/mac-arm64.txt on macOS arm64 / Python 3.11. Direct deps first, then transitive.
# wandb is imported by the upstream training/utils.py but never logged to (WANDB_MODE=disabled).
